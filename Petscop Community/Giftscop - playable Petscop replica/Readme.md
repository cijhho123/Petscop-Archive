# Giftscop - playable Petscop replica

Site documentation for **Giftscop**, the fan project that rebuilds the fictional
Petscop game as something you can actually play. Captured **2026-09-24** from
<https://giftscop.com>.

Giftscop is not a Petscop-inspired game; it is a *replica*. The project's stated
aim is to recreate the game exactly as it exists in the videos, and it tells
players to treat it as a replica rather than a game - matching how things behave
on screen is a higher priority than being fun. That makes it the only fan
project attempting a faithful reconstruction, and the closest thing to a
playable primary source.

It began as a Unity build for Windows and macOS. In 2023 the team shipped a
prototype running on **real PlayStation hardware**, and has since been porting
the whole project to the PS1 with a custom engine.

## A note on the captures

Two MkDocs JavaScript files per page (`bundle.*.min.js` and the search worker)
are referenced but not saved - the capture collects images, stylesheets and
fonts, not scripts. Those scripts drive the search box and nav niceties, not
content, so the pages read correctly without them. Text and images are complete.

Giftscop is a fan project by its own team, unaffiliated with Tony Domenico.
