    Notice

    The archive has been removed due to a security vulnerability impacting all Unity projects built with Unity 2017.1 onwards.

    While this should not affect Giftscop in any way, just to be safe we have removed the download links for builds impacted by this discovery. The current release, 1.2.1, was built with Unity 2019.1.15f1, which patches the issue.

    More information can be found here. Note that while Unity released a tool to patch existing builds, it is not compatible with Giftscop.
