Giftscop - Petscop PS1 Homebrew

A downloadable project for Windows and macOS

Giftscop is a playable replica of Petscop, aiming to recreate the fictional game exactly as it exists in the original story.

We encourage you to view the project more like a replica than a game. The most common complaint we see is that Giftscop is too close to Petscop, and that we should change it to improve parts of the gameplay. While we do not intentionally make things frustrating, whether Giftscop is fun to play is beside the point.

Giftscop was originally created with Unity and released for Windows and macOS. In 2023, we released a small prototype that ran on the original PlayStation. Now, we are working on porting the entire project to the PS1 using a custom engine.

Features:

  • All of the rooms visited in the original series
  • All of the Pets from the original series
  • Input recording system and demos
  • The "P2 to TALK" system used to communicate with other players using a PlayStation controller
  • The "Draw Mode" feature used to edit textures in Petscop 15 (accessible by pressing the buttons corresponding to "Nifty" using P2 to TALK)
  • Near-perfect visual accuracy with the original game
  • Online multiplayer

Some features are not yet supported on the PlayStation version, but will be added in a future update.

In Petscop's community, some thought Petscop was too advanced to run on the PS1. So far, we have overcome all supposed barriers here, including:

  • Dynamic lighting in later portions of the game
  • "Infinite" geometry for the Newmaker Plane
  • Draw Mode with the PS1's limited VRAM
  • Procedural generation of rooms in the Child Library
  • "High-poly" models like the bucket and red tool

The PS1 version is available today, and works on both emulators and actual PS1 hardware.

To hear about the latest updates, report bugs and more, join us on Discord and Bluesky!

More information about the project can be found on our website.
