Description
This template is used to create a basic navigation box.
Syntax
Type {{navbox|<...>}} somewhere, with parameters as shown below.
Sample output
{{navbox
|header=Land of Bob
|body=This [[place]] and that [[place]].
}}

Results in...

Land of Bob
This [[place]] and that [[place]].
