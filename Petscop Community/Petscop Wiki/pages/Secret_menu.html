Secret menu

Namespace: Articles · Revision 10141 · view live · wikitext source
"Who are you?"
This article's name is conjectural, and determined from a non-canon description of its appearance or purpose. Its contents refer to something that has no verified name in Petscop's canon.

The secret menu is a part of the game that can be accessed by entering an esoteric code in the Sound Test menu.

It contains various options related to recordings and a gallery of development images including previous iterations of assets, some of which appear to be unused.

Sections

All Recordings

Main article: Recording

The All Recordings section lists the recordings currently stored on the memory card and saved to the game disc. They can be played back for viewing, along with tweaking the gen it plays back in and toggling an option called "Demo Rot." which is speculated to control whether the recording may appear as a demo on the title screen.

Room Impulse

Main article: Room Impulse

The Room Impulse section lists various rooms in the game. These can be selected and applied with a particular gen to start interactive playback of a currently unknown nature.

Extra Stuff

Main article: Extra Stuff

The Extra Stuff section showcases development images, likely concepts, of pet sprites and locations. Some of what is shown in this menu appears to be unused content.
