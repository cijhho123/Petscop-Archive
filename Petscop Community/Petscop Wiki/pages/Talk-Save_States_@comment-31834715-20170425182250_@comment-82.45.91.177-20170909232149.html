I had an action replay type device for a PS1, and a physical disc copy of Final Fantasy 7. There was specifically a cheat code to allow saving at any time, no matter what. Activating this would allow you quite literally to save anywhere, at any time, that you could bring up the menu without the use of a save point or save crystal, and reloading your save game would reload the game at the exact place you were stood when you saved, no matter what. I don't think it was a "system limitation" that required save points; just a design choice for consoles then. It was easier to "balance" the game if they could limit where and if you could save, perhaps to lengthen gameplay through artificial difficulty via checkpoints/save points.
