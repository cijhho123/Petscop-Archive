Description

This template is used to automate P2 to TALK input combination displays and offer hover-over of the combination.

Usage

Use {{P2}} and add button inputs as additional sets to display the combination.

Valid parameters

NOT case-sensitive Temporarily case-sensitive

  • r1
  • r2
  • l1
  • l2
  • start
  • up
  • down
  • left
  • right
  • square
  • cross
  • circle
  • triangle
  • n ("???" - use for unknown combinations)

Example

{{P2|l2|down|left|l2|triangle|r1|up}}
